# PMI Deletion Denial (DDN) Review: sample procedure

Illustrative test fixture only. Not a real policy.

Input: the loan number.

## 1. Pre-process
1. Pull the loan from MSP: investor class code and the ICMP letter effective date.
2. Determine whether an ICMP letter applies: Y if the letter effective date is present, otherwise N.

## 2. ICMP check
3. If an ICMP letter applies, review the ICMP letter against the investor guidelines and record
   whether the deletion denial is supported.
   Otherwise, record that no ICMP review is needed.

## 3. Approval
4. Send the case to a supervisor for approval.

## 4. Post-process
5. Write the denial verdict summary, citing the loan data and the ICMP review outcome.
